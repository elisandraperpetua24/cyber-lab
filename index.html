Aprender sobre redes

O que é uma rede informática?

É um conjunto de dispositivos ligados entre si para trocar informações e partilhar recursos.

IP Address

É um endereço numérico utilizado para identificar um dispositivo numa rede.

Router

É um equipamento que encaminha dados entre redes.

DNS

É um sistema que ajuda a transformar nomes de domínios em endereços IP.

Firewall

Ajuda a controlar o tráfego de rede de acordo com regras de segurança.
